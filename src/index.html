快速开始

  1. 导入数据：点击“导入测试 CSV / TXT / Excel / DOCX”按钮，或直接将文件拖放到顶部区域；支持多选。
  2. 查看分析：完成字段映射、KPI 计算和异常检测。在“测试总览”和“工况趋势”中查看结果。
  3. 配置规则：选择设备模板，或导入企业配置 JSON 和参数工作簿来调整阈值与目标工况。
  4. 导出成果：生成报告，下载 Markdown、Excel 或 JSON 证据；保存批次后可对比基线。
