这份矩阵是产品验收边界，不是企业标准符合性声明。`已实现`表示代码有可复现证据；`受控试运行`表示可以用脱敏或企业批准数据运行，但仍需要企业批准的 profile、平行验证和人工签核；`待企业输入`表示不能从公开标准或样例数据推断。

历史 v3.5.34 机器证据使用 `.research/ignite_t02_standards_20260821/t02_coverage_audit_v3.5.34.json`、`.research/ignite_t02_standards_20260821/t02_reference_audit_v3.5.34.json` 和全包报告 `.research/ignite_t02_standards_20260821/t02_integration_report_v3.5.34.md`；当前判定以 v3.5.38 证据为准。源资料完整性由 `npm run t02:integrity` 对当前目录逐文件复核，并额外校验审计根目录、记录数和路径唯一性；approved profile 另增加标准引用 provenance、完整方法前置证据、公式复核和 `evaluationMode` 门；下方旧版本路径仅保留历史记录。

### 多文件边界口径

- 多文件导入会保留来源文件、`session_id`、会话时长和边界证据；车辆目标电流段、绝缘窗口、电堆平台和稳定区间均在会话内计算，不把相邻文件的尾首记录拼成一个试验段。
- 车辆主图支持左轴/右轴分别选择数值信号并独立缩放；该双轴是展示与核对能力，不改变 KPI 的核心字段，也不把两个信号混成同一量纲。
- T02 批次审计可以汇总文件级行数、字段目录、指标名称和描述性报告摘要，但当前仍不把不同文件强行合并成一条连续时序 KPI；正式跨文件合并需要企业确认同一试验、时钟、采样和重启边界。
- v3.5.15 提供受控的声明式路径：`testRunId/sessionGroup + fileOrder + clockReference + samplingFrequencyHz/samplingIntervalS + restartBoundaries` 齐全时，watcher/API 才生成 `declared_grouped_sessions` 描述性汇总；批次观测还逐文件核对有效/严格递增时间戳、实际中位采样间隔、声明偏差和跨文件重叠/倒退；文件边界仍保留，输出仍不是标准符合性结论。
- v3.5.16 将同一声明式路径接入静态页和 Vinext 页：上传企业声明后展示脱敏的组状态、实际中位采样间隔、声明偏差、逐文件时间序列状态和问题代码；浏览器不复制批次规则，不展示原始声明标识，不生成标准符合性结论。

## 2. 当前交付门控

页面和报告统一遵循以下状态：

- `ANALYSIS_DRAFT`：默认状态；不能作为放行报告。
- `HUMAN_REVIEW_PACKAGE`：仅当 profile 已审批、数据可用、自动判定为 `PASS`、流程元数据齐全且人工签核字段齐全时进入；仍不等于安全认证或正式符合性结论。
- `BLOCKED_PROFILE_SCOPE`：数据集类型不在 profile 适用范围时直接阻断，避免把车辆规则复用到电堆或耐久数据。

当前内置 profile 是演示模板，阈值不是企业标准。企业正式试运行必须替换为企业批准的字段、单位、测试方法、版本、限值、仪器精度、不确定度预算、签核和审计规则。

## 3. 计量比计算口径

当原始数据没有直接提供氢气/空气计量比、但提供流量、实测电流和片数时，系统按可追溯配置计算：

- 理论耗氢流量：`I × N / (2F) × Vₘ × 60`，单位 SLPM。
- 理论空气流量：`I × N / (4F × yO₂) × Vₘ × 60`，单位 SLPM。
- 计量比：实测流量 / 理论流量。

其中 `F`、`Vₘ`、`yO₂` 和 `N` 保存在结果证据中；默认物理常数只是计算起点，正式报告必须由企业确认标准温压基准、空气氧体积分数、有效片数和流量口径。没有足够参数时状态为未配置，不输出伪造数值。

## 4. 标准边界

已在线核验的公开入口：

- [GB/T 45541-2025 PEM 电解槽性能测试方法](https://std.samr.gov.cn/gb/search/gbDetailed?id=31DA5F377BB68F08E06397BE0A0A4CFB)：现行方法，覆盖基本检查、基础测试、性能测试和报告要求；不能仅凭页面推断企业验收限值。
- [GB/T 46104-2025 电解水制氢系统功率波动适应性测试方法](https://std.samr.gov.cn/gb/search/gbDetailed?id=3DBA213287120D16E06397BE0A0A8119)：现行方法；TestLens 只提供资料和门控入口，不执行试验控制器或安全停机。
- [ISO 22734-1:2025](https://www.iso.org/standard/82766.html)：水电解制氢设备安全要求；TestLens 不替代设备设计安全、联锁、危险分析或安全验证。
- [ISO/IEC 17025:2017](https://www.iso.org/standard/66912.html)：测试/校准实验室能力要求；TestLens 仅辅助记录和复核，不能证明实验室能力或认证状态。

## 5. 企业正式上线前的必需证据

1. 企业标准负责人批准 profile、方法版本、验收准则和单位/温压口径。
2. 测试负责人提供脱敏真实数据和人工基准报告，完成逐指标平行验证。
3. 质量负责人确认报告模板、签核权限、版本留存、原始数据哈希和异常处置流程。
4. 信息安全负责人确认内网部署、账号、访问日志、对象存储和 Feishu 群策略。
5. 在企业指定 Excel/WPS 版本打开真实报告，完成图表、公式、编码和打印视觉验收。
