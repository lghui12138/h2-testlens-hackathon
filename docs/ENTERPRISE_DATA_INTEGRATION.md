# 企业资料结构接入记录

本文件记录 T02 资料包的本机抽样审计结果和产品接入边界。原始企业文件不进入仓库、不进入 GitHub Pages，也不随报告初稿上传。

## 页面侧已实现

- 上传入口支持 CSV、UTF-8/GB18030 TXT 和制表符 TSV；分隔符由表头自动识别。
- 车辆数据自动识别 `FC_*` 信号；目标电流、允许波动和最短持续时间在页面中可调整。
- 电堆数据自动识别中文字段和 `CELL1…`/`单片电压1…` 通道；同一分析同时保留原始字段名到标准字段的映射。
- 真实企业结构的异常只输出证据和下一步动作：时间分辨率不足、字段缺失、单片数量与通道数不一致、绝缘无效码等不会被静默修正。
- 报告初稿和 API 公共响应只发送结构化汇总，不包含原始行；`publicAnalysis` 会移除 `rows`。

## 仍未宣称完成的部分

1. 浏览器当前不直接读取 XLSX；资料包 01 的出厂报告 XLSX 作为参考模板，仍需后续增加安全的工作簿读取器。
2. 车辆多文件合并、每日增量扫描、飞书固定人员告警和服务端审计存储尚未接入；当前先处理用户选中的单个 CSV。
3. 电堆任务书要求的“数据处理设定参数/目标工况设定”Excel 双表、完整平台/稳定区间和标准化 Excel 输出尚未完成；当前版本只做到真实字段接入和一致性摘要，并明确阻断正式符合性结论。
4. 企业没有提供批准的阈值、仪器精度、不确定度预算和签核规则，因此不能把当前结果写成企业通过、标准符合或安全放行。

## 验证方式

自动化测试使用脱敏合成行复现企业表头，不把原始样本复制进仓库；本机回放另外读取下载目录中的车辆 CSV、127 列 CSV 和 422 列 TXT，检查数据集识别、时间轴、目标电流段、绝缘窗口、单片通道和报告导出路径。
