## 页面侧已实现

- 上传入口支持 CSV、UTF-8/GB18030 TXT、制表符 TSV 和原始时序 XLSX；Excel 会从最匹配时间/电流/电压字段的工作表读取，不把参数工作簿当成原始数据。
- 车辆数据自动识别 `FC_*` 信号；目标电流、允许波动和最短持续时间在页面中可调整。
- 电堆数据自动识别中文字段和 `CELL1…`/`单片电压1…` 通道；同一分析同时保留原始字段名到标准字段的映射。
- 真实企业结构的异常只输出证据和下一步动作：时间分辨率不足、字段缺失、单片数量与通道数不一致、绝缘无效码等不会被静默修正。
- 页面专用图与表使用同一结构化结果：车辆图绘制绝缘趋势和 350/250 kΩ 线，电堆图绘制有效极化点并区分 60–120 s 短稳定点。
- 耐久 DOCX 解析保留原始报告元数据和功率点来源；未配置企业预警阈值时只显示原始结果，不新增判定。
- 飞书告警默认不外发；只有填写企业批准的 V2 webhook 并点击确认发送才会尝试 POST，发送结果保留在当前页面，不保存 webhook/密钥。
- 参数/目标工况 Excel 按工作表名、表头和参数代码读取，不依赖固定行号；校验失败时阻断正式平台/稳定区间处理。
- 页面提供 [`config/enterprise-parameter-template.xlsx`](../config/enterprise-parameter-template.xlsx) 下载入口；模板中的数值仅是填写格式示例，不是企业标准。
- Excel 报告导出包含 14 个工作表、目标/实际偏差公式、字段映射、数据质量、平台、稳定区间、单片统计、异常和处理日志；报告不包含原始时序行。
- 报告初稿和 API 公共响应只发送结构化汇总，不包含原始行；`publicAnalysis` 会移除 `rows`。

## 仍未宣称完成的部分

1. 资料包 01 的出厂报告 XLSX 是参考报告，不是参数工作簿；系统会明确拒绝把它误当成“数据处理设定参数/目标工况设定”。
2. 浏览器多文件批次导入已支持；每日自动增量扫描、飞书固定人员告警和服务端审计存储尚未接入。
3. Excel 报告当前保留“图表数据”工作表，尚未写入 Excel 原生嵌入图表；网页端趋势图仍可直接查看。
4. 企业没有提供批准的阈值、仪器精度、不确定度预算和签核规则，因此不能把当前结果写成企业通过、标准符合或安全放行。

## 验证方式

自动化测试使用脱敏合成行复现企业表头，不把原始样本复制进仓库；本机回放另外读取下载目录中的车辆 CSV、127 列 CSV 和 422 列 TXT，检查数据集识别、时间轴、目标电流段、绝缘窗口、单片通道和报告导出路径。
