## 2026-08-24 · 时间轴缺口感知积分轮

- 当企业 profile 明确配置最大采样间隔时，产氢量、电能和不确定度传播会跳过超限时间段，不再跨未知时间段做梯形积分。
- 阶段覆盖、阶段持续时间和阶段积分同步识别该缺口；原始缺值和非正时间间隔继续跳过，不进行插值。
