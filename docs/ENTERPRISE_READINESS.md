# 企业应用与标准符合性审计

## 结论

当前版本不是“完全符合所有标准”的系统，也不是认证软件。接入本次资料包后，它可以进入企业的受控试运行，承担车辆 CSV/电堆 CSV/GB18030 TXT 的结构识别、指标计算、异常初筛和报告初稿整理；正式的符合性结论、放行决定和安全判断仍必须由企业批准的方法、质量体系和授权人员完成。

依赖与输入安全边界：package.json 不再声明未被源码直接使用的 npm `xlsx` 依赖，`npm audit --omit=dev` 当前无直接生产依赖高危项；实际 XLSX 解析仍由仓库内 `src/vendor/xlsx.full.min.js`（SheetJS 0.18.5 兼容 bundle）承担。该 bundle 只应在本地/内网受控试运行中处理已批准来源的工作簿，不能据此宣称第三方解析器已完成安全认证；正式生产部署前仍需替换或隔离解析器，并完成恶意/超大工作簿测试。

## 逐项判断

| 范围 | 当前证据 | 判定 |
|---|---|---|
| GB/T 45541-2025 PEM 电解槽性能测试 | 已支持独立 PEM 四段 profile（基本检查、基础测试、性能测试、测试报告）、系统组成/环境/条件/测量方法证据门控、字段映射、流量/纯度/能耗等字段和报告初稿；没有标准全文中的全部仪器精度、试验条件、应急措施和计算/验收规则 | 部分满足，不能宣称符合 |
| GB/T 46104-2025 功率波动适应性 | 已有测试计划、结构化采集记录、逐项前检查、测试系统组成、环境条件、测量方法、原始电压/电流/电功率通道、稳态/动态/启停阶段 KPI 与阶段结果证据入口；没有完整的功率波动试验控制、企业批准的采样精度/动态速率/功率一致性规则和停机试验执行器 | 部分满足，不能替代试验 |
| 测试段覆盖 | profile 可声明 `requiredPhases`，适配器只使用输入中的真实阶段/工况字段；缺少阶段、阶段指标或原始行连续性不满足 profile 时进入 `NOT_READY` | 可门控，仍需真实试验计划确认 |
| 标准测试阶段 | `requiredTestStages` 与 `workflowSequence` 按具体方法声明顺序和阶段 id 逐项要求状态/证据；46104 与 45541 使用不同公开流程映射 | 已实现结构化门控；不执行测试控制器 |
| 测试系统组成 | `testSystemRequirements` 要求 profile 声明的电源、电解槽、分离/纯化、循环、热管理和控制系统证据 | 已实现逐项结构化门控；不从 CSV 推断系统存在或符合 |
| 测试条件 | `testConditionRequirements` 可要求测试场所、系统配置和异常处置引用 | 已实现结构化门控；不猜条件值或安全限值 |
| 环境条件 | `environmentConditionRequirements` 独立要求环境温度、湿度、气压等记录及证据引用 | 已实现独立门控；不把环境记录当作标准限值 |
| 方法阶段结果 | `phaseResultRequirements` 要求冷/热启动、稳态、动态、停机等阶段结果与证据引用 | 已实现结果证据门控；不把通用 KPI 自动宣称为标准结果 |
| 测量方法 | `measurementMethodRequirements` 可要求电输入、气体输出、环境和高频采集方法引用 | 已实现结构化门控；不替代仪器精度/校准证明 |
| 效率 | `efficiencyRequirement` 只接受实测 `efficiency_pct` 或企业批准结果记录 | 已实现 fail-closed；没有批准公式/数据就不计算 |
| ISO 22734-1:2025 水电解制氢安全 | 只保存适用范围和标准引用，不执行设备设计安全、联锁、危险分析或安全验证 | 不满足认证用途 |
| ISO/IEC 17025:2017 实验室能力 | 支持仪器、仪器精度、校准、执行者、公式、不确定度和签核字段；没有实验室公正性、能力授权、质量记录、审核和正式电子签章 | 可作记录辅助，不能证明实验室符合 |
| 测量不确定度 | profile 可提供 `first_order_rss` 模型、覆盖因子和各测量标准不确定度；没有模型时系统不填默认误差 | 可计算辅助，必须由企业批准模型确认 |
| 工作簿公式/活动内容 | XLSX/XLSM 进入 SheetJS 前阻断 VBA、ActiveX/OLE 和外部链接；公式单元格只读取缓存值并形成计数/风险审计；验收或 `FULL_METHOD_IMPLEMENTED` 必须提供公式复核证据 | 已实现 fail-closed 输入边界和公式 provenance；不执行/重算公式，仍需企业批准复核和隔离解析器 |
| AI 治理 | 有结构化证据、冲突回退、离线 grounding 测试和不发送原始行的边界 | 仅为风险控制原型，不是 ISO/IEC 42001 或 23894 认证 |
| 企业生产系统 | 可部署到独立 GitHub Pages；当前原始行、历史和报告主要在浏览器端，未接企业工单、权限、数据库、审计日志和邮件认证 | 适合受控试运行，不适合直接作为正式系统 |
| 批次增量追溯 | 浏览器本地 manifest 已记录文件 SHA-256、大小、记录数和新增/变更/未变；尚未接企业对象存储、数据库审计和定时调度 | 可作受控试运行批次证据，不是生产审计系统 |
| 内部批次运行器 | 支持明确目录、`--once`/间隔扫描、profile、报告输出和显式 `--send-alerts`；尚未接企业调度器、对象存储、权限和正式审计数据库 | 可作内网受控试运行，不能直接当生产服务 |
| profile 审批证据 | `approvalStatus: approved` 必须绑定审批人标识、审批日期、批准依据/工单号、与当前 `revision` 一致的 `profileRevision` 和修订证据引用；标准引用还必须有状态、方法来源、范围/流程证据、发布日期/实施日期并与 `methodId` 绑定；缺失/不一致 fail-closed，公开接口只返回存在性 | 已实现结构化门控；真实审批记录和标准全文仍需企业提供 |
| 测试对象追溯 | profile 可声明 `testRunId/deviceId/testType/testDate/cellCount/activeAreaCm2/evidenceRef`；缺失或格式错误时 approved profile 进入 `NOT_READY`，公共面只保留字段数量/状态 | 已实现结构化门控；真实对象主数据、企业编号规则和原始证据仍需企业提供 |
| 人工修改审计 | profile 可要求 `editLog` 的字段、旧值摘要、新值摘要、操作者、时间、原因和证据引用；记录缺失或不完整时 approved profile 进入 `NOT_READY` | 已实现结构化门控；对象存储、数据库审计、权限和电子签章仍需企业系统接入 |
| 完整方法实施证据 | 带标准引用的 `FULL_METHOD_IMPLEMENTED` 必须绑定方法来源、条款/步骤覆盖、逐项实施证据、验证人、验证日期、验证引用、空 `openGaps`，以及企业验收规则、仪器类别要求、`uncertaintyModelRequired: true` 和有效不确定度模型；任一缺失、错配、部分实施或有未关闭缺口时 fail-closed，不进入人工复核包 | 已实现结构化门控；真实标准全文、企业方法执行器、批准限值、不确定度预算和验证记录仍需企业提供 |
| 报告交付门控 | 报告记录 `ANALYSIS_DRAFT` 或 `HUMAN_REVIEW_PACKAGE`，由 approved profile、审批证据、质量、PASS、流程和人工签核共同决定 | 防止分析草稿被误当放行报告 |
| 执行者报告字段 | 报告 profile 可独立要求 `operator` 与 `operatorQualification`；缺少资质/授权依据时保持 `NOT_READY` | 只记录证据存在性，不证明实验室认可或人员能力 |
| 本次企业资料结构 | 已接入车辆 `FC_*` 信号、127 列中文电堆 CSV、422 列 GB18030 制表符 TXT；支持参数/目标工况 Excel、14 表报告、多文件批次、OOXML 图表路径和服务端 Feishu 通道；自动增量、企业群策略、Excel/WPS 视觉验收和服务端审计仍未完成 | 业务闭环部分可运行，不能宣称生产合规 |
| 台架耐久资料 | 已解析耐久 DOCX 的原始测试结果和功率点，并支持企业自行填写离均差/平均单体电压预警规则；浏览器确认发送和服务端环境变量通道均有安全边界，企业群策略/工单闭环/审批仍未接入 | 可用于受控预警初筛，不能替代原始报告或放行签核 |

## 企业试运行的最低前置条件

1. 企业标准负责人提供批准的 profile：设备范围、标准/方法版本、字段字典、单位、仪器精度、验收准则和不确定度规则。
2. 测试负责人提供脱敏真实数据，并确认时间同步、采样频率、通道单位、稳态/动态/启停边界和异常处置流程；将这些证据按批准 profile 填入 `acquisitionRecord` 与 `preCheckItems`。
3. 质量负责人确认报告模板、签核权限、版本留存、原始数据哈希和审计记录要求。
4. 信息安全负责人确认数据是否允许浏览器本地处理、是否需要内网部署、账号系统和访问日志。
5. 用真实数据完成平行验证：TestLens 与现有人工/实验室报告逐项比对，未通过前只输出“分析初筛”。

## 明确禁止的产品表述

- “符合 GB/T 45541-2025”或“通过 ISO 22734-1:2025”。
- “替代实验室、测试负责人或安全工程师”。
- “AI 自动判断设备安全”。
- 用内置演示阈值作为企业放行限值。
